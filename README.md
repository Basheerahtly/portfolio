# Portfolio Website

My personal portfolio, built to present my skills, education, achievements and projects as a Computer Science (AI) student at Asia Pacific University.

## Built with

- **Next.js** and **React** for the pages and components
- **TypeScript** for safer code
- **Tailwind CSS** for styling
- **Web3Forms** for the contact form

## Features

- Light and dark themes, with the visitor's choice remembered
- Sidebar navigation that becomes a slide-in menu on phones
- A contact form that delivers messages to my email
- All content stored in one file, `data/portfolio.ts`, so the site can be updated without changing the code

## Project structure

- `app/` holds the page, the layout and the global styles
- `components/` holds one file per section of the site
- `data/portfolio.ts` holds all the text content
- `public/` holds images and my CV

## Running it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in a browser.
